# ui_library — COMPONENTS.md

Machine-readable inventory of the public surface in `lib/widgets/` and
`lib/services/`. Generated by reading the sources (class declarations + doc
comments) — when a widget's tiers change, update its row and its doc comment
together. Tiers name the real engine; "—" means no separate tier (the widget
is pure Flutter on that platform).

The canonical tier matrix + stock-widget ban list lives in
[`../core/NATIVE_COMPONENTS.md`](../core/NATIVE_COMPONENTS.md) — read it
before reaching for any primitive; this file is the inventory, that file is
the law.
