# showcase_app intake artifacts

Intake artifacts for the showcase app, **generated** by the appboxd intake
pipeline from the hand-authored seed. Per repo rules: edit the seed
(`answers.json`), never the generated outputs.

## Files

- `answers.json` — SEED (hand-authored, validated by `appbox intake validate`)
- `brief.md`, `registry.json`, `flows.json`, `personas.json`, `map.json` —
  GENERATED by `appbox intake emit`. `map.json` is the story map; tests cite
  its story ids verbatim (ids are content-derived kebab slugs, stable as long
  as the story name in the seed does not change).

## Regenerate

The engine only emits the full artifact set into a project shell
(`$APPBOX_HOME/projects/<name>/intake/`), so emit against a throwaway
APPBOX_HOME and copy the outputs back into the repo:

```bash
# from the repo root
cd appboxd
dart run bin/appbox.dart intake validate ../kit/showcase_app/intake/answers.json

rm -rf /tmp/appbox-showcase
APPBOX_HOME=/tmp/appbox-showcase dart run bin/appbox.dart intake emit \
  --answers ../kit/showcase_app/intake/answers.json --project showcase

cp /tmp/appbox-showcase/projects/showcase/intake/{map.json,flows.json,personas.json,brief.md,registry.json} \
  ../kit/showcase_app/intake/
```

## Validate

```bash
# schema check (needs `pip install jsonschema`)
python3 -c "
import json, jsonschema
jsonschema.validate(
  json.load(open('kit/showcase_app/intake/map.json')),
  json.load(open('skills/appbox-story-mapper/story-map.schema.json')))
print('map.json: VALID')"
```
