The intake skill (plan 10). An optional phase — the head of one chain whose tail (`arxa emit story-map`, arxa-story-mapper) emits the unified brief — that elicits validated answers and seeds the registry.json (at the design root: `designs/<app>/models/screens_model/registry.json`, or structure.json's `"registry"` field) the designer consumes. Belongs: the elicitation engine (`arxa/lib/intake.dart` — `arxa intake emit|seed|validate`), its answers schema, and artefact emission. Does not belong: design or code generation, the desktop wizard UI (app/), or the traceability gate (`arxa gate intake`, `arxa/lib/gate_intake.dart`).
