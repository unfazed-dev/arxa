The intake skill (plan 10). An optional phase — the head of one chain whose tail (`appbox emit story-map`, appbox-story-mapper) emits the unified brief — that elicits validated answers and seeds the registry.json (at the design root: `designs/<app>/models/screens_model/registry.json`, or structure.json's `"registry"` field) the designer consumes. Belongs: the elicitation engine (`appboxd/lib/intake.dart` — `appbox intake emit|seed|validate`), its answers schema, and artefact emission. Does not belong: design or code generation, the desktop wizard UI (app/), or the traceability gate (`appbox gate intake`, `appboxd/lib/gate_intake.dart`).
