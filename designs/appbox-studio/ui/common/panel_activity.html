{# THE ACTIVITY PANEL — the shell's multi-view panel. Vocabulary is fixed in ui/common/_integration_panels.md. This panel uses all three of the stacked sections and neither side: top the active view's label body the caller's content for that view bottom the views carousel — one icon per registered view Each shell registers its own views (design: screens / artifacts / files; build: runs / commits / files; intake: thread / artifacts / files). Macro-only, so importing it never emits stray markup. {% import "ui/common/panel_activity.html" as pa %} {% call pa.frame(spec) %} …markup for the active view… {% endcall %} spec: label — the active view's label, shown in the top section views — [{ id, icon, label, href, active }], one carousel button each; icon is a Lucide name for the icon() global, href hx-swaps that view's fragment into #panel-activity-body size? — 's' | 'm' | 'l' (default 's'): the shell's persisted width step, used as the panel-size-* fallback when panelSizePx is unset sizeHref? — present when the panel can be resized; renders the drag rail on the panel's START edge panelSizePx? — persisted px width; when set, applied as an inline width instead of the panel-size-* fallback The panel owns and persists its own state: the element carrying the user's drag-resized width is never replaced. A view switch swaps the BODY in place and refreshes the top and bottom sections out-of-band, so the active icon and the label always track the server. That is why top() and bottom() are standalone macros with an `oob` flag as well as parts of frame(). There is no `side` argument. This panel is identified by its ROLE, and its id is the constant `panel-activity`; it sat on the left when it was written and on the right now, and neither fact belongs in its name. #} {% import "ui/common/panel.html" as pn %} {% set PID = 'panel-activity' %} {% macro label(spec) %}{{ spec.label }}{% endmacro %} {% macro views(spec) %}
{% for v in spec.views %} {{ icon(v.icon, {size: 18}) }} {% endfor %}
{% endmacro %} {# ---------- the sections, standalone (for out-of-band refresh) ---------- #} {% macro top(spec, oob) %}{{ pn.top(PID, label(spec), oob) }}{% endmacro %} {% macro bottom(spec, oob) %}{{ pn.bottom(PID, views(spec), oob) }}{% endmacro %} {% macro frame(spec) %}
{# RESIZE RAIL — the panel's own edge IS the handle: no icon, the edge lights up on hover and the cursor turns col-resize. Rendered by frame(), never by a section, so an out-of-band section refresh cannot drop it mid-drag. edge:'start' is a fact about this rail, not about the shell — see panels.css, which keys the rail entirely on [data-edge]. #} {% if spec.sizeHref %}{{ pn.resize(PID, { edge: 'start', persist: 'activity' }) }}{% endif %} {{ pn.top(PID, label(spec)) }} {{ pn.body(PID) }}{{ caller() }}{{ pn.bodyEnd() }} {{ pn.bottom(PID, views(spec)) }}
{% endmacro %}
