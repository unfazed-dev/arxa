{# THE COMPOSER PANEL — the shell's chat panel, shared across every stage. Vocabulary is fixed in ui/common/_integration_panels.md. Single-state and permanent: always mounted, never closed (the retired two-state chat dock is gone). Sections: top the stage eyebrow and the pinned-context chips body the caller's thread + composer card bottom OFF — deliberately. The composer card already pins to the floor of the body and IS this panel's action surface; a bottom section beneath it would be a second floor with nothing to stand on it. The caller renders thread + composer card inside frame(); these macros provide the panel shell and the top section's content. Macro-only file. spec: eyebrow — the stage line, e.g. "intake · interview" chips — [{ id, label, tone?, removeHref? }] pinned conversation context (design's pinned screens, build's gate refs); tone is one of cyan/olive/amber/violet, cycling by index when absent; removeHref adds the unpin (×) action The context filmstrip is not here. It is the main panel's side-end section in the views lens (ui/views/main_shell/shared/widgets/design_viewer.html); the composer's own tray (ui/views/main_shell/shared/widgets/composer.html) carries one only on surfaces with no viewer. #} {% import "ui/views/main_shell/shared/widgets/panel.html" as pn %} {% set PID = 'panel-composer' %} {# The top section's CONTENT — the section element itself comes from pn.top, so this panel's head and the activity panel's head are the same box with different things inside. That is the entire point of the contract: before it, one was a bordered
and the other a bare flex row called .chat-head, and nothing made them agree. #} {% macro headContent(spec) %} {% set tones = ['cyan', 'olive', 'amber', 'violet'] %} {{ spec.eyebrow }} {% if spec.chips %} {% for chip in spec.chips %} {{ chip.id }}{{ chip.label }}{% if chip.removeHref %}{{ icon('x', {size: 12}) }}{% endif %} {% endfor %} {% endif %} {% endmacro %} {% macro top(spec, oob) %}{{ pn.top(PID, headContent(spec), oob) }}{% endmacro %} {# Wrap with call/caller: {% call cp.frame(spec) %}thread + composer card{% endcall %} #} {% macro frame(spec) %}
