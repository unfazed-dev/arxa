{# THE ACTIVITY PANEL — the shell's multi-view panel. Vocabulary is fixed in ui/common/_integration_panels.md. A thin instantiation of _panel.html: it owns its content and its state, and none of the skeleton. This panel uses all three stacked sections and neither side: top the active view's label body the caller's content for that view bottom the views carousel — one icon per registered view Each shell registers its own views (design: screens / artifacts / files; build: runs / commits / files; intake: thread / artifacts / files). Macro-only, so importing it never emits stray markup. {% import "ui/views/main_shell/shared/widgets/activity_panel.html" as pa %} {% set A = spec %} {{ pa.open(A) }} …markup for the active view… {{ pa.close(A) }} Open/close rather than {% call %}: nunjucks binds caller() to the nearest enclosing {% call %}, so this panel could not forward its body to the base while itself being called. `appbox design lint` (W4) checks the pair is balanced per template. spec: label — the active view's label, shown in the top section views — [{ id, icon, label, href, active }], one carousel button each; icon is a Lucide name for the icon() global, href hx-swaps that view's fragment into #panel-activity-body size? — 's' | 'm' | 'l' (default 's'): the shell's persisted width step, used as the panel-size-* fallback when panelSizePx is unset sizeHref? — present when the panel can be resized; renders the drag rail on the panel's START edge panelSizePx? — persisted px width; when set, applied as an inline width instead of the panel-size-* fallback The panel owns and persists its own state: the element carrying the user's drag-resized width is never replaced. A view switch swaps the BODY in place and refreshes the top and bottom sections out-of-band, so the active icon and the label always track the server. That is why top() and bottom() are standalone macros with an `oob` flag as well as parts of open()/close(). There is no `side` argument. This panel is identified by its ROLE, and its id is the constant `panel-activity`; it sat on the left when it was written and on the right now, and neither fact belongs in its name. #} {% import "ui/common/widgets/_panel.html" as base %} {% set PID = 'panel-activity' %} {% macro label(spec) %}{{ spec.label }}{% endmacro %} {% macro views(spec) %}
{% for v in spec.views %} {{ icon(v.icon, {size: 18}) }} {% endfor %}
{% endmacro %} {# ---------- the sections, standalone (for out-of-band refresh) ---------- #} {% macro top(spec, oob) %}{{ base.top(PID, label(spec), { oob: oob }) }}{% endmacro %} {% macro bottom(spec, oob) %}{{ base.bottom(PID, views(spec), { oob: oob }) }}{% endmacro %} {# open() and close() each derive the base spec from the SAME caller spec, so the two cannot disagree about which trailing sections exist. #} {% macro open(spec) %} {{- base.open({ role: 'activity', id: PID, size: (spec.size or 's') if not spec.panelSizePx, width: spec.panelSizePx, top: label(spec), bottom: views(spec), resize: { edge: 'start', persist: 'activity' } if spec.sizeHref }) -}} {% endmacro %} {% macro close(spec) %} {{- base.close({ role: 'activity', id: PID, bottom: views(spec) }) -}} {% endmacro %}
