# Vendored fonts — Lexend superfamily

Downloaded 2026-07-28 from fonts.gstatic.com (Google Fonts API, `css2`),
latin + latin-ext subsets. All three families are by Thomas Jockin /
Font Bureau and published under the **SIL Open Font License 1.1** —
free to use, embed, and redistribute; no attribution required at runtime.
License text: https://openfontlicense.org

| File | Family | Weight | Subset |
|---|---|---|---|
| `lexend-var-latin.woff2` | Lexend (variable) | 300–700 | latin |
| `lexend-var-latin-ext.woff2` | Lexend (variable) | 300–700 | latin-ext |
| `lexend-giga-latin.woff2` | Lexend Giga | 300 / 400 | latin |
| `lexend-giga-latin-ext.woff2` | Lexend Giga | 300 / 400 | latin-ext |
| `lexend-deca-500-latin.woff2` | Lexend Deca | 500 | latin |
| `lexend-deca-500-latin-ext.woff2` | Lexend Deca | 500 | latin-ext |

Usage (see `assets/css/app.css`):

- **Lexend Giga 300–400** — display headlines
- **Lexend 400 (variable)** — body text
- **Lexend Deca 500** — tracked-caps UI labels / eyebrows
